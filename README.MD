### Featured Projects

#### 🎧 Shuusshy — Desktop Noise-Cancellation Application

**Shuusshy** is an independent Windows desktop application I created to help users achieve cleaner microphone audio by reducing unwanted background noise.

The project explores real-time audio processing and noise suppression technologies, with an emphasis on simplicity, usability, and a minimalist desktop experience.

Key development goals include:

- Real-time microphone noise suppression.
- Integration of RNNoise and DeepFilterNet technologies.
- Microphone testing with sound activity indicators.
- Interactive audio monitoring to help users evaluate noise reduction.
- A lightweight, minimalist Windows interface.
- Portable and installable application distribution.

**Technologies:** Tauri, Rust, JavaScript, RNNoise, DeepFilterNet.
