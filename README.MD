## 🚀 Featured Projects

### 🎧 Shuusshy — Desktop Noise-Cancellation Application

**Shuusshy** is an independent Windows desktop application I created to improve microphone audio quality by reducing unwanted background noise.

The project combines audio processing technologies with a lightweight desktop experience, focusing on accessibility, simplicity, and practical real-time noise suppression.

**Key Features & Development Goals**

- Real-time microphone noise suppression.
- Integration of RNNoise and DeepFilterNet technologies.
- Microphone testing and sound activity indicators.
- Interactive audio monitoring to evaluate noise reduction.
- Minimalist and user-friendly desktop interface.
- Portable and installable Windows application.
- Application lifecycle and update management.
